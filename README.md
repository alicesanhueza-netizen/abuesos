# AbueSOS

Aplicación web instalable y accesible para personas mayores.

- Botón para abrir la llamada al SAMU 131 en Chile.
- Configuración de un contacto de confianza en el dispositivo.
- Interfaz adaptable y textos grandes.
- Soporte básico sin conexión después de la primera visita.

## Importante

La aplicación abre el marcador telefónico; el teléfono puede pedir confirmación. No llama automáticamente, no comparte ubicación y no notifica por sí sola a familiares. Prueba la instalación y las llamadas con cuidado antes de depender de ella en una emergencia.

Es una aplicación web estática: no necesita un proceso de compilación. Se debe servir por HTTPS para instalarla desde el navegador.
